# Raspberry Pi 5 Bootable Image

This directory contains the final bootable disk image generated by the
**Raspberry Pi 5 Custom Embedded Linux BSP** project.

## Contents

```text
Bootable/
├── README.md
└── rpi5_custom.img
```

### `rpi5_custom.img`

`rpi5_custom.img` is a raw disk image intended to be written directly to an
SD card and used to boot the Raspberry Pi 5.

The image contains an MBR partition table and a FAT32 boot partition.

```text
rpi5_custom.img
│
├── MBR / DOS partition table
│
└── Partition 1
    ├── FAT32
    ├── Raspberry Pi DTB
    ├── Device Tree overlays
    ├── config.txt
    ├── cmdline.txt
    ├── Linux kernel image
    └── rootfs.cpio.gz
```

The image is generated from the project's `rpi_bootfs` directory.

# Generating the Image

The bootable image can be generated independently when `rpi_bootfs` has
already been prepared.

From the project root:

```bash
./lib/rpi5_image.sh
```

The generated image is:

```text
Bootable/rpi5_custom.img
```

The image generation process is:

```text
rpi_bootfs/
     │
     ├── Kernel
     ├── DTB
     ├── DT overlays
     ├── config.txt
     ├── cmdline.txt
     └── rootfs.cpio.gz
              │
              ▼
       rpi5_image.sh
              │
              ▼
       Create raw image
              │
              ▼
       Create MBR partition table
              │
              ▼
       Create FAT32 partition
              │
              ▼
       Attach loop device
              │
              ▼
       Format FAT32
              │
              ▼
       Mount partition
              │
              ▼
       Copy rpi_bootfs
              │
              ▼
             sync
              │
              ▼
       Unmount partition
              │
              ▼
       Detach loop device
              │
              ▼
       rpi5_custom.img
```

# Using the Image

## Flash to an SD Card

The image can be written to an SD card using a graphical imaging tool such
as Raspberry Pi Imager, or with a raw disk-writing utility.

### Important

**Verify the target device before writing the image.**

Writing an image to the wrong block device can permanently destroy data on
that device.

For example, first inspect:

```bash
lsblk
```

Then verify the SD card device before performing any raw write operation.

# Relationship to the BSP

The bootable image is the final packaging stage of the platform:

```text
                 CUSTOM EMBEDDED LINUX BSP
                            │
             ┌──────────────┴──────────────┐
             │                             │
        Kernel / BSP                  Userspace
             │                             │
      ┌──────┼──────┐              ┌───────┼───────┐
      │      │      │              │       │       │
   PREEMPT   DT   Drivers        BusyBox Dropbear rt-tests
      RT      │                     │       │       │
              │                     └───────┼───────┘
              │                             │
              │                           ROOTFS
              │                             │
              └──────────────┬──────────────┘
                             │
                             ▼
                         rootfs.cpio.gz
                             │
                             ▼
                         rpi_bootfs
                             │
                             ▼
                    rpi5_image.sh
                             │
                             ▼
                     rpi5_custom.img
                             │
                             ▼
                       Raspberry Pi 5
```

The image therefore represents the **deployment artifact** of the BSP
rather than the development source itself.

# Rebuild the Complete Platform

To rebuild the root filesystem and then generate the bootable image:

```bash
./scripts/build_rootfs_pipeline.sh custom-sdk --bootable
```

To generate only the image from an existing `rpi_bootfs`:

```bash
./lib/rpi5_image.sh
```

# Verification

After generating the image, verify its partition table:

```bash
fdisk -l Bootable/rpi5_custom.img
```

Expected structure:

```text
Disklabel type: dos

Device                 Boot   Start      End
rpi5_custom.img1       *      2048       ...
```

The first partition should be a FAT32 partition containing the Raspberry Pi
boot files.

You can also verify the image size:

```bash
ls -lh Bootable/rpi5_custom.img
```

# Project Status

This image is the final bootable artifact produced by the custom Raspberry
Pi 5 Embedded Linux BSP build pipeline.

The BSP currently includes:

- ARM64 cross-compilation
- Fixed SDK/sysroot
- Raspberry Pi downstream Linux kernel
- PREEMPT_RT configuration
- Device Tree / DTB
- Device Tree overlays
- BusyBox
- Dropbear
- rt-tests
- Runtime dependency resolution
- Custom initramfs
- Raspberry Pi boot filesystem
- Automated bootable image generation

---

> **Do not manually edit the generated `.img` file.**
>
> Make changes in the kernel, Device Tree, rootfs, or `rpi_bootfs`, then
> regenerate the image using `lib/rpi5_image.sh`.
